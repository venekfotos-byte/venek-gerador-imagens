1. Foto do produto

Para peças técnicas, use foto nítida com boa iluminação. Confirme visualmente a fidelidade antes de publicar.

2. O que deseja criar?

3. Configure a imagem

A IA pode errar letras e detalhes de peças. A imagem gerada deve ser revisada antes de anunciar.

🔒 Preservar produto original: ATIVADO

A IA separa o produto do fundo. Os pixels do produto na imagem final vêm da sua foto original, sem recriar dentes, cores ou encaixes. Confira o contorno do recorte antes de anunciar.

4. Gerar imagem

A interface está pronta. Para gerar de verdade, conectaremos a API segura na próxima etapa.

A geração com API pode ter custo por imagem. Nenhuma cobrança é realizada enquanto a API não estiver conectada.

⚙ Configuração da conexão IA

Configure depois que publicarmos o servidor. Não coloque sua chave da OpenAI aqui. Este app usa uma senha de acesso e um endereço de servidor seguro.

A opção de manter conectado salva a senha no navegador deste aparelho. Não utilize em computadores compartilhados.
